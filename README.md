# Ren'PyndIDE

> 运行在 Android 上的 Ren'Py 集成开发环境（IDE）——脚本编辑、游戏编译、APK 打包与 AI 助手，全部在手机上完成。开源免费。

## 编辑器
- 脚本编辑：Ren'Py 语法处理、文本选择菜单、代码模糊显示
- 文件树：私有目录 / 公共目录 / 自定义路径，随时切换，一键切回原路径
- 布局助手：可视化辅助布局
- 缓存机制：编译与资源缓存，二次构建更快

## 编译与运行
- 原生桥接：设备端直接运行 Ren'Py 脚本
- 游戏编译：完整进度反馈，支持中途取消
- 错误诊断：编译日志捕获与展示

## APK 打包
- RAPT 一键打包为 Android APK
- SDK 下载、安装与路径配置
- Gradle / build-tools / 签名密钥的完整管理
- 实时构建日志，一键复制
- 自定义启动图、图标、应用名与版本号

## AI 助手
- 多协议：OpenAI / Claude / Gemini，多服务商档案独立隔离
- 模型列表与余额查询、流式输出、思考链与正文分离
- 内置 Python 运行时，移植 renpy-mcp 80+ 工具
- 工具按组渐进加载，上下文自动压缩，过滤设备端不可用工具
- 思考/正文去重、聊天历史搜索、Markdown 渲染、字号调节
- ask_user 交互卡片，支持多轮对话

## 多语言支持（本次更新）
- 6 种语言：跟随系统 / 简体中文 / 繁體中文 / English / 日本語 / Русский，切换即时生效
- 内置译文：英文约 82%、繁中约 97%、日语俄语约 47%，未命中项回退简体中文
- 自定义翻译包：导入 / 导出 JSON，覆盖内置译文
- 用 `t("中文原文")` 包裹即可纳入翻译，支持 `{0}` 占位符

详细用法见 [I18N_GUIDE.md](I18N_GUIDE.md)。
